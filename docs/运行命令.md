# 运行命令

> 环境：Ubuntu 18.04 / ROS Melodic / Jetson Nano
> 运行前先执行：`source ~/catkin_ws/devel/setup.bash`

---

## 节点一览

| 节点名 | 文件 | 功能简述 |
|--------|------|---------|
| `gps_node` | `gps_driver/scripts/gps_publisher.py` | 读取 GPS 串口，解析 NMEA，发布坐标（WGS84→GCJ02） |
| `jetbot_serial_control` | `n10_slam/scripts/jetbot_serial_control.py` | 与 STM32 串口通信，收发速度/IMU/电压数据 |
| `odometry_node` | `n10_slam/scripts/odometry_node.py` | 积分里程计，发布 `/odom` 和 TF |
| `n10_lidar_node` | `n10_slam/scripts/n10_lidar_node.py` | 驱动 N10 激光雷达，发布 `/scan` |
| `aliyun_ros_node` | `aliyun_pkg/scripts/aliyun_node.py` | MQTT 连接阿里云 IoT，接收目标坐标并下发到 ROS |
| `camera_node` | `camera_pkg/scripts/camera_node.py` | 采集摄像头图像，发布 `/image`（25fps，320×240） |
| `face_recognizer` | `camera_pkg/scripts/face_node.py` | 订阅 `/image`，用 dlib HOG 检测并识别人脸，发布识别结果 |
| `face_trainer` | `camera_pkg/scripts/face_trainer.py` | 人脸数据采集与训练工具（交互式） |
| `packet_node` | `packet_pkg/scripts/packet_node.py` | 汇聚人脸识别和 GPS 数据，打包发布 `/packet_data` |
| `jetbot_keyboard_control` | `packet_pkg/scripts/jetbot_keyboard.py` | 键盘控制小车（w/a/s/d），同时发布 `/cmd_vel` 和串口指令 |
| `navigation_controller` | `n10_pkg/scripts/navigation_controller.py` | 订阅 GPS + 目标坐标 + 规划路径，输出 `/cmd_vel`，含简单避障 |
| `path_planner` | `n10_pkg/scripts/path_planner.py` | A* 路径规划，将 GPS 坐标转为网格路径并发布 `/planned_path` |
| `robot_control_gui` | `n10_slam/scripts/robot_control_gui.py` | PyQt5 图形控制面板，集成摇杆/键盘控制、节点管理、传感器显示 |
| `battery_monitor` | `battery_monitor.py` | 独立脚本，监控电池电压，低于 10.85V 时自动安全关机 |

---

## 话题关系

```
/dev/ttyUSB0 ──► gps_node ──────────────────────────────► /gps_data
/dev/ttyACM0 ──► jetbot_serial_control ──► /sensor/cmd_vel ──► odometry_node ──► /odom
                                       └──► /imu/data
                                       └──► /battery_voltage
/dev/ttyTHS1 ──► n10_lidar_node ────────────────────────► /scan
/camera      ──► camera_node ──► /image ──► face_recognizer ──► /recognized_face_name
阿里云 MQTT  ──► aliyun_ros_node ────────────────────────► /navigation/destination
/gps_data + /navigation/destination ──► path_planner ──► /planned_path
/gps_data + /planned_path + /scan   ──► navigation_controller ──► /cmd_vel
/gps_data + /recognized_face_name  ──► packet_node ──► /packet_data
```

## 单节点运行命令

### GPS 节点
```bash
# 默认串口 /dev/ttyUSB0，波特率 9600
rosrun gps_driver gps_publisher.py

# 指定串口
rosrun gps_driver gps_publisher.py _port:=/dev/ttyUSB1 _baudrate:=9600
```

### STM32 串口通信
```bash
# 默认串口 /dev/ttyACM0
rosrun n10_slam jetbot_serial_control.py

# 指定串口
rosrun n10_slam jetbot_serial_control.py _port:=/dev/ttyACM1
```

### 里程计
```bash
# 依赖 /sensor/cmd_vel，需先启动串口节点
rosrun n10_slam odometry_node.py
```

### N10 激光雷达（Python 驱动）
```bash
# 默认串口 /dev/ttyTHS1
rosrun n10_slam n10_lidar_node.py

# 自定义参数
rosrun n10_slam n10_lidar_node.py _port:=/dev/ttyTHS1 _frame_id:=laser_frame
```

### 阿里云 IoT 节点
```bash
rosrun aliyun_pkg aliyun_node.py
```

### 摄像头节点
```bash
rosrun camera_pkg camera_node.py
```

### 人脸识别
```bash
# 需先启动摄像头节点
rosrun camera_pkg face_node.py
```

### 人脸训练（采集数据）
```bash
# 启动后按 't' 开始录制，输入姓名，自动保存 10 张图片
rosrun camera_pkg face_trainer.py
```

### 数据打包节点
```bash
rosrun packet_pkg packet_node.py
```

### 键盘控制
```bash
# 需先启动串口节点
rosrun packet_pkg jetbot_keyboard.py
# 控制键：w前进 s后退 a左转 d右转 x停止 c退出
```

### 路径规划
```bash
rosrun n10_pkg path_planner.py
```

### 导航控制
```bash
rosrun n10_pkg navigation_controller.py
```

### 图形控制面板
```bash
python3 src/n10_slam/scripts/robot_control_gui.py
```

### 电池监控（独立脚本，非 ROS 节点）
```bash
python3 battery_monitor.py
# 建议开机自启，监控 /dev/ttyJETBOT，低于 10.85V 自动关机
```

## Launch 文件

### 底盘基础控制（串口 + 里程计 + 雷达）
```bash
roslaunch n10_slam base_control.launch

# 指定串口
roslaunch n10_slam base_control.launch stm32_port:=/dev/ttyACM0
```

### GMapping 建图
```bash
roslaunch n10_slam n10_gmapping.launch
```

### 导航（需已有地图）
```bash
roslaunch n10_slam n10_navigation.launch

# 指定地图文件
roslaunch n10_slam n10_navigation.launch map_file:=$HOME/my_map.yaml
```

### 摄像头 + 人脸识别
```bash
roslaunch camera_pkg face.launch
```

### 一键启动（GPS + 串口 + 阿里云）
```bash
roslaunch start_all.launch
```

## 常用辅助命令

```bash
# 串口授权
sudo chmod 666 /dev/ttyACM0 /dev/ttyTHS1 /dev/ttyUSB0

# 保存地图
rosrun map_server map_saver -f ~/my_map

# 查看激光数据
rostopic echo /scan

# 查看 GPS 数据
rostopic echo /gps_data

# 查看人脸识别结果
rostopic echo /recognized_face_name

# 查看电压
rostopic echo /battery_voltage

# 手动发布速度（测试用）
rostopic pub /cmd_vel geometry_msgs/Twist "linear: {x: 0.2}" -r 10
```

## 推荐启动顺序

```
1. roscore
2. 串口授权
3. roslaunch n10_slam base_control.launch   ← 底盘 + 雷达
4. rosrun gps_driver gps_publisher.py       ← GPS
5. rosrun camera_pkg camera_node.py         ← 摄像头
6. rosrun camera_pkg face_node.py           ← 人脸识别
7. rosrun aliyun_pkg aliyun_node.py         ← 云端通信
8. roslaunch n10_slam n10_gmapping.launch   ← 建图（或导航）
```
