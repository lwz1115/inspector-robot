# 运行命令

> 环境：Ubuntu 18.04 / ROS Melodic / Jetson Nano  
> 运行前先执行：`source ~/catkin_ws/devel/setup.bash`


一：摄像头 + 人脸识别 + web视频流
```bash
roslaunch camera_pkg face.launch
```
启动后包含：
- `camera_node`：采集摄像头画面，发布 `/image`
- `web_video_server`：MJPEG 流，端口 8081
- `face_node`：人脸识别（由 `/face_cmd` 控制启停）
- `face_trainer`：人脸训练（由 `/face_train_cmd` 控制）

视频流地址：`http://192.168.1.104:8081/stream?topic=/image`


二：串口通信（STM32数据收发）
```bash
rosrun packet_pkg serial_node.py
```
启动后包含：
- `serial_node`：与 STM32 串口通信，默认端口 `/dev/ttyACM0`
- 订阅电量、烟雾、温湿度等传感器数据，发布到对应 topic
- 低电量自动触发关机保护
  


三：室内建图（Web 显示）
```bash
roslaunch n10_slam n10_gmapping_web.launch
```
启动后包含：
- `lslidar_driver_node`：N10 激光雷达驱动，串口 `/dev/ttyN10`
- `odometry_node`：里程计节点
- `slam_gmapping`：gmapping 建图
- `map_node`：订阅 `/map`，将地图转 PNG base64 推送到 Spring Boot

地图推送地址：`http://192.168.1.103:8080/api/map/push`  
前端建图页面实时显示，切换到「室内建图」菜单即可查看

> 换网络时覆盖参数：`roslaunch n10_slam n10_gmapping_web.launch backend_url:=http://<Windows_IP>:8080/api/map/push`
